# MelBet Tutorial

Этот репозиторий для обучения по текущему проекту MelBet.

Что внутри:
- базовые заметки по структуре лендинга;
- рабочий процесс с Git;
- чек-лист перед публикацией.

## Структура обучения
1. Подготовка проекта
- структура: `index.html`, `contact.html`, `css/`, `js/`, `assets/`
- проверка локального запуска: `python3 -m http.server 5500`

2. Работа с версткой
- якорная навигация на главной странице
- адаптивные секции и мобильное меню
- базовые анимации и интерактивные блоки

3. Работа с формой
- отдельная страница `contact.html`
- валидация обязательных полей
- чекбоксы согласий + ссылки на Terms/Privacy

4. Git-практика
- маленькие логические коммиты
- проверка `git status` перед пушем
- пуш в `main` после завершения задачи

## Быстрый чек-лист перед пушем
- сайт открывается локально;
- ссылки не битые;
- мобильная версия не ломается;
- нет лишних файлов (`.DS_Store` и т.д.);
- коммит содержит понятное сообщение.
